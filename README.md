# Blender 系统学习笔记

本仓库整理 Blender 的通用概念、学习顺序、操作要点和排错方法，适用于 Blender 4.5 LTS 附近的版本。各版本的界面、快捷键和功能可能不同，以实际安装版本及官方手册为准。

## 学习路线

1. 熟悉界面、视图导航、对象与编辑模式、坐标和变换。
2. 学习网格建模、拓扑、法线、修改器和场景组织。
3. 学习材质节点、贴图、UV、灯光、相机与色彩管理。
4. 学习关键帧、曲线、约束、骨骼、变形与非线性动画。
5. 学习刚体、布料、流体、粒子、几何节点和缓存。
6. 学习渲染、合成、视频剪辑、声音、输出和交付。
7. 学习 Python 自动化、性能优化、故障排查和版本管理。

详细笔记见 [Blender 通用学习手册](blender-guide.md)。建议按章节做小练习，并保留测试文件、记录问题与参数；读过文档不等于已经掌握，每个专题都应通过实际操作复核。
